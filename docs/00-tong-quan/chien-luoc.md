# Chiến lược & bối cảnh VinSOC

Chinh đang học khóa AI 3 tháng (2 tháng học + 1 tháng thực tập), mục tiêu vào chương trình fresher AI tại VinSOC: 11 đề tài, 20 slot, 3 mentor. Đề tài chia sau khi vào công ty, không chọn trước. Kỳ thực tập là kỳ đánh giá lên nhân viên chính thức.

**Chiến lược**: không cạnh tranh trên trục security thuần (ai cũng mạnh, công ty cần ít nhất) mà trên trục **đồ thị + LLM + kỹ thuật dữ liệu**. Toàn bộ 8 tuần dồn vào một sản phẩm demo duy nhất.

**11 đề tài VinSOC** (tần suất công nghệ: LLM/RAG/agent 8/11, đồ thị 7/11, Python 7/11, OpenSearch 3/11, SIEM API 2/11, công cụ security cổ điển 1/11):

1. Exposure Management & Attack Path Prediction — Neo4j, OpenSearch, RAG/LLM, risk scoring
2. Context Intelligence & Security Knowledge Graph — Neo4j, GraphQL, entity resolution, LLM trích xuất quan hệ
3. Attack Surface Management — DNS/CT, Nmap/Nuclei, Graph DB, LLM phân loại
4. Triage Agent SOC Tier 1 — SIEM API, OpenSearch, RAG, LLM agent, ML
5. AI Agent điều tra sự cố SOC Tier 2 — RAG, Graph DB, SIEM/EDR API, LangGraph
6. UEBA/Anomaly Detection — Isolation Forest, LOF, OCSVM, VAE, LSTM-VAE, PySpark
7. Graph Application in Cybersecurity — BFS/Dijkstra, PageRank, GNN, Louvain, PySpark
8. AI Assistant in Data Platform — LangChain/LlamaIndex, RAG/GraphRAG, Text2SQL
9. Shadow AI — AI service inventory, OWASP GenAI, MITRE ATLAS, Neo4j, OpenSearch, MCP
10. AI Redteam/Blueteam — OWASP LLM Top 10, MITRE ATLAS, guardrail
11. AI BOM — AST parsing, cyclonedx-python-lib, HuggingFace/deps.dev API

Dự án demo bám chủ yếu đề tài #1, #2, #7, chạm #8.

Kế hoạch 8 tuần gốc: `../../Let's go.html` (lưu ở root thư mục). Tài liệu hướng dẫn tạo bài giảng: Google Doc "system-prompt-bai-giang.md" (nguồn đề tài VinSOC + chương trình module ở trên).
