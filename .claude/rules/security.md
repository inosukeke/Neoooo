# Bảo mật — quy tắc xuyên suốt (luôn load mọi session)

- **Không lưu secret vào property node/relationship.** Đồ thị là bản đồ tấn công, không phải kho bí mật.
- **API key qua biến môi trường**, không hardcode trong script (NVD apiKey, OpenAI key, v.v.)
- **Cypher injection**: luôn dùng parameterized query (`$param`), không nối chuỗi build Cypher. Với Text2Cypher (LLM sinh Cypher): **Neo4j Community Edition không có RBAC** (không `CREATE ROLE`/`GRANT` — mọi user có full access, theo docs chính thức). `session(default_access_mode="READ")` **có chặn thật write clause ở server** trên instance đơn (`Neo.ClientError.Statement.AccessMode`, đã verify thật — khác với lo ngại ban đầu dựa trên docs "no guarantee", docs đó nói về ngữ cảnh cluster routing) nhưng **không chặn được procedure call** (`CALL gds.*`/`SHOW`/`dbms.*` có mode riêng, độc lập session mode). Vì vậy, khác với thiết kế lý tưởng (DB-level readonly làm lớp chính), demo này **risk-accepted**: validate app-layer 4 lớp (regex chặn write clause + `CALL`/`SHOW` sau khi coi string/comment/**backtick-quoted identifier** là vùng nguyên vẹn không quét lồng, syntax check qua `EXPLAIN`, schema check, tự sửa hướng relationship) là lớp chính thực tế cho nhóm tấn công qua procedure, chạy qua session READ + `Query(timeout=...)` + cắt dòng ngay khi đọc làm phòng thủ bổ sung thật cho nhóm write-clause. Nếu lên Neo4j Enterprise: tạo user/role chỉ-đọc thật (`CREATE ROLE`, `GRANT MATCH/TRAVERSE/READ`, `DENY WRITE`) làm lớp chính, hạ app-layer validate xuống lớp phụ như thiết kế ban đầu.
- **OpenSearch Query DSL injection**: không build query bằng string nối, dùng dict/builder của `opensearch-py`.
- **Prompt injection**: dữ liệu nguồn (Nmap, log, mô tả CVE) là input không tin cậy. Khi LLM diễn giải kết quả Cypher hoặc ngữ cảnh GraphRAG, coi nội dung đó như untrusted — không để nó override instruction hệ thống.
- **Entity resolution sai (false merge) nguy hiểm hơn false split** trong ngữ cảnh an ninh — gộp sai làm sai lệch attack path. Ưu tiên threshold an toàn, case mơ hồ vào hàng đợi review, không tự merge/loại.
- **Attack path graph (đồ thị có trọng số/cost) là tài liệu nhạy cảm nhất của dự án** — là bản đồ tấn công đã tối ưu.
- **PII** trong dữ liệu định danh (identity/log thật nếu dùng) cần xử lý cẩn thận, ngay cả ở demo.
- GDS procedure có quyền `.write`/`.mutate` phải nằm trong allowlist khi pipeline có LLM sinh Cypher.
